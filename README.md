persiapan
1. pastkan sudah menginstal xampp di komputer
2. download file webnya di github https://github.com/unabbanu/portal-mahasiswa-uap
3. extrak zip yang baru didownload
4. rename foldernya jadi "uap" tanpa tanda petik
5. copy foldernya di directory C:\xampp\htdocs
6. buka xampp 
7. start apache dan mysql
8. klik admin di mysql atau buka browser ketik localhost/phpmyadmin


import database
1. buat database baru bernama uap
2. import database uap.sql di data base uap yang baru dibuat tadi


buka tab baru jalankan web dengan mengetik localhost/uap
